# ARROW PUZZLE

盤面に並んだ矢印をタップして、すべて取り除くブラウザパズルゲームです。

## 遊び方

- [`index.html`](index.html) を開いて「いますぐ遊ぶ」を押す、または [`game/Arrow.v2.html`](game/Arrow.v2.html) を直接ブラウザで開きます。
- インストールやビルドは不要です。

## ルール

1. 取り除きたい矢印をクリック（タップ）します。
2. 先端の向きに、盤面の端まで他の矢印がなければ飛んでいきます。
3. 邪魔な矢印があると動けません。先に別の矢印をどかします。
4. 動かせない矢印を3回選ぶとゲームオーバーです。
5. すべての矢印を消したらクリアです。

## 難易度

| モード | 内容 |
| --- | --- |
| 通常モード | 8×8マス |
| 難しいモード | 16×16マス、矢印の数が4倍 |
