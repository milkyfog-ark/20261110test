# ARROW PUZZLE

盤面に並んだ矢印をタップして、すべて取り除くブラウザパズルゲームです。

## 遊び方

- [`index.html`](index.html) を開いて「いますぐ遊ぶ」を押す、または [`game/Arrow.v2.html`](game/Arrow.v2.html) を直接ブラウザで開きます。
- インストールやビルドは不要です。

## 3D版（Arrow.v3）

- [`game/Arrow.v3.html`](game/Arrow.v3.html) は、正立方体版の続編です。立方体の各面が盤面になり、矢印は辺を越えて2面・3面にまたがって配置されます。
- 判定は先端からその面の端までの直線のみ。除かれる矢印は、蛇のように自身の経路をなぞって這い出ます（他の面へ移動することはありません）。
- ドラッグで立方体を回転、ピンチで拡縮できます。ふつう（4×4×6面・14本）と むずかしい（5×5×6面・24本）の2モード、ライフ♥3、ウインドベル風のループBGMと効果音付きです。

## ルール

1. 取り除きたい矢印をクリック（タップ）します。
2. 先端の向きに、盤面の端まで他の矢印がなければ飛んでいきます。
3. 邪魔な矢印があると動けません。先に別の矢印をどかします。
4. 動かせない矢印を3回選ぶとゲームオーバーです。
5. すべての矢印を消したらクリアです。

## 難易度

| モード | 内容 |
| --- | --- |
| 通常モード | 8×8マス |
| 難しいモード | 16×16マス、矢印の数が4倍 |
